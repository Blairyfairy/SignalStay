# SignalStay — Search intelligence
Independent portfolio case study by Blair Page, November 25, 2026.

A fictional hospitality campaign demonstrates keyword planning, match types, funnel strategy, negative keywords, CPA and conversion-rate analysis, and optimization decisions. All numeric data is synthetic. No original coursework or client data is included.

## Deploy
Upload the contents of this folder to a GitHub repository root. In Settings → Pages choose Deploy from a branch, main, / (root). No dependencies or API keys required. Open index.html locally to preview.

## Data
`data/campaign.csv` contains the same synthetic observations embedded in `app.js`. Metrics are calculated in the browser. The format comparison chart always shows the full dataset.

## Brand assets
Original editable SVG wordmarks, icon, favicon, hero illustration and social card are in `assets/`. The visual system uses midnight navy, mint and cool white.
